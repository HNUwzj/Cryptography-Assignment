# 密码学及应用课程实验

## 1 任务
开发一个密码学核心算法及协议综合服务系统

---

## 2 功能说明

### 2.1 界面要求
设计一个加解密综合服务菜单式展示界面（B/S 或者 C/S 皆可）

### 2.2 密码学核心算法及协议

#### 2.2.1 仿射加密
- 加密密钥可配置（通过 XML 等文件形式输入）

#### 2.2.2 大整数运算（128 位）
- 两个 128 位的整数加、减、乘运算（需自建类实现）

#### 2.2.3 流密码加密
- 密钥流生成方式至少包括以下两种：
  - RC4
  - LFSR + J-K 触发器
- 种子密钥可配置（通过 XML 等文件形式输入）

#### 2.2.4 对称加密
- DES 加密
- 加密密钥可配置（通过 XML 等文件形式输入）

#### 2.2.5 非对称加密
- RSA 加密算法（自行构造）
  - 模数规模 < 16 bit
  - 支持大于 16 bit 的消息加密

#### 2.2.6 基于 D-H 认证协议及增强的大通量安全通信
- 必须有两个参与实体（C/S 模式）
- 必须有网络通信部分
- 实现消息完整性验证及来源验证的增强设计：
  - 散列函数：SHA-1 或 MD5
  - 数字签名：RSA
- 实现 **1G 以上容量文件**的加密传输

---

## 3 设计说明

- 所有基础算法必须构建在一个 **DLL**、**LIB** 或 **JAR 包**中
- 除特别说明外，可调用 `crypto++` 或开发语言自带的算法组件或接口
